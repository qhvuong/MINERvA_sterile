\subsection{Scope and reproducibility}

Individual checks are recorded in \texttt{assertions.csv}; score decompositions in \texttt{scores.csv}; per-bin implied variance and standard-deviation ratios in \texttt{implied\_scale\_by\_bin.csv}. Runtime versions, loaded C++ libraries, tolerances and run status accompany the report. Production runs also save input paths, SHA-256 hashes and matrix snapshots. These tests establish or falsify identities for the specified objective. They do not establish an optimal elbow, complete physical flux uncertainty, or oscillation coverage.
